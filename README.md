# Программирование на языке Python. Лабораторная работа №1.

## Работа программы

За время выполнения работы был реализован Python-пакет с CLI, содержащий калькулятор и конвертер величин.

Стандартные команды для терминала:
```text
python -m toolkit calc "EXPRESSION"
python -m toolkit convert VALUE --from UNIT --to UNIT
python -m toolkit --help
```
### Калькулятор поддерживает:

- Рациональные числа
- Операции `+`, `-`, `*`, `/`.
- Унарный `+` и `-` перед числом.
- Пробелы между составляющими выражения.

### Конвертер поддерживает:

- Унарный `+` и `-` перед числом.
- Длина: `mm`, `cm`, `m`, `km`.
- Масса: `g`, `kg`.
- Температура: `c`, `f`, `k`.

## Методика

### Калькулятор
Программа разделяется на tokenization, validation и calculation.

1. Выражение проходит первичную валидацию, выводится ошибка, программа завершается с кодом 2, если:
- В записи выражения внутри записи числа есть пробел
- В записи выражения есть неизвестные символы
- В записи выражения есть деление на 0
- Запись выражения заканчивается на операцию
2. Выражение проходит токенизацию:
- Каждый токен это либо операция, либо число с унарным знаком или без него
3. Токенизированное выражение проходит вторичную валидацию, выводится ошибка, программа завершается с кодом 2, если:
- Запись выражения начинается с операции
- В выражении есть две операции подряд
- В выражении есть нецелые числа, написанные с ошибкой
4. Токенизированное выражение становится постфиксным представлением с помощью Shunting Yard Argorith
5. Постфиксное представление считается с помощью стека
6. Выводится ответ, программа завершается с кодом 0

### Конвертер

1. Выражение проходит валидацию, выводится ошибка, программа завершается с кодом 2, если:
- Были даны несуществующие величины
- Перевод между величинами разного типа
- Температура меньше абсолютного нуля
2. Происходит перевод значения:
- Если не температура, то значение переводится линейно согласно словарю
- Если температура, то значение переводится по формуле
3. Выводится ответ, программа завершается с кодом 0
