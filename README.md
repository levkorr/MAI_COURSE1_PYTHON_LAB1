# Программирование на языке Python. Лабораторная работа №1.

## Работа программы

Программа: Python-пакет с CLI, содержащий калькулятор и конвертер величин.

Стандартные команды для терминала:
```bash
python -m toolkit calc "EXPRESSION"
python -m toolkit convert VALUE --from UNIT --to UNIT
python -m toolkit --help
```
### Калькулятор поддерживает:

- Вещественные и целые числа.
- Операции `+`, `-`, `*`, `/`, `//`, `%`.
- Унарный `+` и `-` перед числом.
- Приоритеты между операциями.
- Пробелы между составляющими выражения.

### Конвертер поддерживает:

- Унарный `+` и `-` перед числом.
- Длина: `mm`, `cm`, `m`, `km`.
- Масса: `g`, `kg`.
- Температура: `c`, `f`, `k`.

### Возможные ошибки:

#### Ошибки калькулятора (CalculatorError):

- `SequentialOperationsError` - выражение содержит несколько операций подряд
- `FloatOperandError` - выражение содержит вещественное число, написанное с ошибкой
- `OperationsStartError` - выражение начинается с операции
- `OperationsEndError` - выражение заканчивается на операцию
- `DivisionByZeroError` - выражение содержит деление на ноль
- `SplitNumberError` - выражение содержит число внутри которого присутствует пробел
- `UnknownSymbolsError` - выражение содержит неизвестные символы
- `IntSpecialOperationsError` - выражение содержит целочисленное деление (извлечение остатка) вещественных чисел

#### Ошибки конвертера (ConverterError):

- `UnknownUnitsError` - конвертация между неизвестными величинами
- `DifferentUnitTypesError` - конвертация между величинами разных типов
- `BelowAbsoluteZeroError` - конвертация значения, которое меньше абсолютного нуля
- `InvalidValueError` - задано неверное значение

## Методика

### Считываение аргументов
1. Происходит считывание аргументов из командной строки с помощью argparse
2. Происходит анализ аргументов
- Если первый аргумент это calc, то происходит считываение "EXPRESSION", вызывается калькулятор
- Если первый аргумент это convert, то происходи считывание VALUE, UNIT, UNIT, вызывается конвертер

### Калькулятор
Программа разделяется на tokenization, validation и calculation.

1. Выражение проходит первичную валидацию:
- Если есть ошибка: Вызывается дочерний класс от CalculatorError, программа завершается с кодом 2
2. Выражение проходит токенизацию:
- Каждый токен это либо операция, либо число, либо число с унарным знаком
3. Токенизированное выражение проходит вторичную валидацию:
- Если в токенизированном выражение есть ошибка: Вызывается дочерний класс от CalculatorError, программа завершается с кодом 2
4. Инфиксная запись превращается в постфиксную с помощью Shunting Yard Argorithm
5. Постфиксное представление считается с помощью стека
6. Выводится ответ
7. Данные об успешном запуске заносятся в successful_launches.json
8. Программа завершается с кодом 0

### Конвертер

1. Выражение проходит валидацию:
- Если есть ошибка: Вызывается дочерний класс от СonverterError, программа завершается с кодом 2
2. Происходит перевод значения:
- Если температура, то значение переводится в кельвины, затем в требуемую температуру согласно конфигурационному файлу
- Если не температура, то значение переводится в базовую величину(метры, граммы), затем в требуемую, согласно конфигурационному файлу
3. Выводится ответ
4. Данные об успешном запуске заносятся в successful_launches.json 
5. Программа завершается с кодом 0
